# UD택시 기사 앱 — 모바일 웹 (React + TypeScript)

피그마 `MVP_2조` 디자인을 바탕으로 만든 기사 앱 화면 흐름입니다. React 18 + TypeScript + Vite로 만들었습니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (휴대폰 크기로 보세요)
npm run build    # 타입 검사 후 dist/ 에 빌드
```

## 화면 흐름

1. **근무 시작** — 장비 점검(슬로프·휠체어 고정 장치·안전벨트), 이상 시 장비 이상 신고 → 배차 제외
2. **다음 손님 기다리는 중** — 휴게 / 일반 손님 태움 / 근무 종료, 10초 뒤 새 호출
3. **새 호출** — 3분 수락 카운트다운, 시간 초과 시 다른 기사에게 넘어감
4. **출발지로 이동 중** — 남은 시간·거리, 길 안내, 승객 연락
5. **도착했어요(손님 찾기)** — 손님 정보, 빠른 메시지, 전화, 못 탔어요
6. **손님이 못 탔나요?** — 미탑승 이유 선택 후 보고
7. **출발 전 확인** — PV5가 휠체어 고정·안전벨트·슬로프·문을 차례로 확인
8. **운행 중** — 도착까지 15분 · 4.7km, 손님 메시지와 답장, 곧 하차 표시
9. **목적지 도착** — 앱카드 결제 진행 중, 5초 뒤 하차 지원으로 이동
10. **하차 지원 중 → 하차했어요** — 하차 확인 단계, 결제 완료/실패(직접 결제), 탑승 문제 기록(직접 입력·저장), 5초 뒤 자동으로 다음 배차

## 구조

```
src/
  App.tsx            화면 전환과 근무 상태(대기·배차·운행 기록)
  AppContext.tsx     음성 안내, 토스트, 설정(음성·큰 글자)
  data.ts            예시 데이터와 데모 타이밍
  screens/           화면 11개 (StartScreen … DropScreen)
  sheets/            아래에서 올라오는 시트 (장비 점검, 이상 신고, 알림, 메뉴, 근무 종료)
  components/        TopBar, Layer, StepList, Chips
  hooks/             타이머, 단계 진행, 화면 꺼짐 방지
prototype/index.html 처음 만든 단일 HTML 프로토타입(참고용)
```

## 참고

- 데모를 위해 이동·운행 시간은 빠르게 진행되고, 결제는 50% 확률로 실패합니다. 값은 `src/data.ts`의 `TIMING`에서 바꿀 수 있습니다.
- 승객 정보, 안심번호, 공지·알림 내용은 예시 값입니다.
- 폰트는 Pretendard(설치된 경우) → Noto Sans KR 순서로 적용됩니다.
